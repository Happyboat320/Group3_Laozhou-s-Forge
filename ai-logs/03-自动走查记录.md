# 03 · 自动走查记录

> 这份记录写于「加三种玩法」之前，当时的交付流程只有时机玩法一种。加了玩法之后的三种玩法走查见 04-三种玩法.md。

规则能测，但画面和手感测不了。所以写了一个走查脚本，让它在真浏览器里从封面一路打到结算，每个阶段截一张图，顺便把控制台的报错收集下来。

## 怎么跑

```bash
# 1. 起一个带调试端口的 Chrome（配置目录放在项目里，不污染系统）
chrome --headless=new --remote-debugging-port=9222 --user-data-dir=.chrome-profile about:blank

# 2. 走查：开 dev server、连上浏览器、自动玩一遍
node verify/tour.mjs
```

脚本每帧读 `ctx.debug()` 里的指针位置，靠近中心才出手——这样走查出来的成色是「会玩的人」的水平，顺便验证了判定窗口是能打中的。

## 走查抓到的四个问题

1. **接单页**：气泡压住了订单卡，`要求成色` 和徽章上的名字叠在一起 → 重排卡片。
2. **打造页**：阶段文字压在铁砧上 → 铁砧缩小上移，文字挪到砧子下方。
3. **打造页**：锤子悬在半空，没砸在铁坯上 → 重摆位置和角度，落锤时一并下移。
4. **淬火**：背景里本来就有一只水桶，我又摆了一只，成了两只；而且铁坯被桶挡住看不见 → 桶挪到铁砧右侧，落手时铁坯沉进桶里、冒一股蒸汽。
