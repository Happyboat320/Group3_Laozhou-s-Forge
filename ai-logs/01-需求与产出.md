# 01 · 需求与产出

## 人提的要求（按时间顺序）

1. 「还是这门课的作业（命题《老周的铁匠铺》），玩法选**肉鸽**。」
2. 「老师 PPT 第三讲讲了素材不够怎么办，你不能解决吗，然后能成功完成一个**地牢探险**的肉鸽？」
3. 「我是不是可以让组员去搞定图片素材，让你直接先开始做？」
4. 「角色的移动和怪物的移动要**自由的**，不是一格一格跳，要连续移动；怪物自动朝角色移动。」
5. 「怪物只在**看得见**（直线上没障碍）时才追我，其余随机移动。」
6. 「视野外要**全黑**，视线是直线，被墙挡住。」
7. 「攻击键随时能按；挖矿要**按键**（长按 K）；挖完矿石图案消失。」
8. 「箱子桶有**实体**，不能穿过，能砸碎，砸碎后可以通过。」
9. 「锻造可以选更高级的材料，也可以多投料；投得越多越好，上限越高。」
10. 「挖矿概率改成 生铁 50 / 铜精 35 / 陨铁 15；有宝箱加成变 40/40/20。」
11. 「地图都是重复的，要每次随机生成。」
12. 「怪物要源源不断地生成。」
13. 「打碎桶或箱子后地面还显示桶，这不应该。」
14. 「这些游戏参数希望能自己改，都在同一个文件吗？」

## 对照产出

| 要求 | 落在哪 |
|---|---|
| 命题不变、接单交付不变 | `core/game.ts` 的订单/交付；`scenes/shop.ts`、`scenes/forge.ts` |
| 地牢作为「取料」环节 | 每单缺料 → 下窟挖 → 回炉打 |
| 连续移动 + 滑墙 + 怪物实时追 | `core/run.ts` 的 `slide()`、`updateRun()` |
| 视线判定（Bresenham） | `core/run.ts` 的 `lineOfSight()` / `computeVisible()` |
| 视野外全黑 | `scenes/delve.ts` 的 `redraw()` |
| 按键挖矿、矿石消失 | `updateRun()` 的 `input.mine`、`delve.ts` 的贴图清理 |
| 箱桶实体 + 可砸 | `core/run.ts` 的 `props`、`playerCanStand()`、`smash` 事件 |
| 多材料配比 | `core/game.ts` 的 `materialCap()` / `canCraft()`，`scenes/shop.ts` 的配比面板 |
| 掉落概率 | `config.ts` 的 `dropRates`，`core/game.ts` 的 `rollMaterial()` |
| 地图每次不同 | `core/dungeon.ts` 的槽位数/房间大小/起终点随机，种子按"局+单"区分 |
| 刷怪 | `updateRun()` 里的 `mobSpawnIn`，`config.combat` 的 `mobSpawnEvery` / `maxMobs` |
| 砸完还显示桶 | 删掉了那层纯装饰的箱桶（`scenes/delve.ts` 的 `drawDecor`） |
| 参数集中 | 全部在 `src/config.ts` |

## 代码规模

- `src/` 约 2600 行（core 约 900，scenes 约 1500，config 130）
- 测试 49 项，`npm run check` 全过
- 无第三方素材（全部课程素材包 + 自写合成音）
