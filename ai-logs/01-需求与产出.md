# 01 · 需求与产出

## 人提的要求

> 「D:\codes\3chuang\游戏\try 直接在这个文件夹内按照他们提供的文件完成整个实验。不要修改这个文件夹以外的东西。」

拆成三条约束：

1. **只用课程给的材料**：`AI Native的游戏开发实践.zip` 里的学生任务书、参考框架（2D/3D 起步模板、音游打铁案例、3D 场景示例）和素材包。
2. **全部产出都在 `游戏/try` 里**：源码、依赖、截图、打包、日志，一个都不能落到外面。
3. **按任务书的要求做完整个实验**：能完整玩到结算、三天循环、三种以上器型、有手感的打造环节、新手提示、美术与声音达标、README 与 AI 创作日志、可离线运行的 release。

| 材料 | 怎么用的 |

| `实践-学生/实践课题：《老周的铁匠铺》学生任务书.docx` | 定要求：核心循环、必做项、提交物、评分 |
| `参考框架/网页游戏起步模板` | 直接作为项目骨架（TypeScript + Vite + Phaser 4） |

| `参考素材/2D图片`、`CC0原包`、`AI生成2d-3d小游戏素材包` | 起步模板里已经按 ID 登记好了 180 张图，直接用 |
| 三份课件（第 1/2/3 讲） | 方法：游戏三层、先灰块跑通再换素材、好指令 = 范围 + 禁止 + 验收 |

## 任务书要求逐条对照

| 要求 | 落点 |
|---|---|
| 能完整玩到结算 | 封面 → 接单 → 打造 → 交付 → 下一天 → 结算，走查跑通 |
| 循环至少 3 轮 | 三天，一天两单，共 6 单 |
| 至少 3 种订单 / 器型 | 柴刀、锄头、马蹄铁、镰刀、长剑、匕首（6 种） |
| 至少 1 个有操作手感的打造环节 | 三种可选：火候→三锤→淬火 / 三条道节奏打铁 / 五条道火候控制；都有震屏、火花、音效 |
| 有简单的新手提示 | 第一次进打造场景弹一次说明，存档记住 |
| 至少 1 个场景、2 个角色形象、物品图标、基础 UI | 铁匠铺 + 接单两张背景；樵夫 / 王婶 / 货郎 / 厨娘 / 镖师 / 老周 6 位角色；6 种器型图标；HUD、判定槽、订单卡、徽章 |
| 背景音乐 + 至少 3 种音效 | 合成 BGM + 9 种音效（敲打、落空、淬火、收钱、交付、废品、点击、节拍） |
| 核心循环闭环，每轮影响下一轮 | 成色影响金币与口碑；口碑决定输赢；三天三关，每关收摊算账 |
| 明确结束条件 + 结算画面 | 口碑 ≤ 0 提前收摊，或三天后按口碑判定；结算页逐单明细 + 评语 |
| AI 创作日志 4~6 个环节 | README 表格 6 行 + `ai-logs/` 三份原始记录 |
| release 可离线运行 | `npm run pack` 单文件 `release/index.html` |
| git 提交记录随包提交 | 没代做：仓库留给组员自己 `git init` 后分阶段提交 |
