# 新手引导与重玩流程 · 2026-11-21

## 用户要求与代理判断

用户：“你看看还有什么需要加的就做一下然后commit一下吧”。

代理检查现有场景与配置后，选择补齐操作说明和再次游玩的流程。没有新增玩法、依赖或改变成色阈值。本轮提示、审查和测试由 Codex 代理执行，尚不代表真人试玩结论。

## 发现、提示与产出

| 发现 | 代理拟定的修改要求 | 最终处理 |
|---|---|---|
| 火候卡片仍写 14 秒、剩余炉温决定成色；实际为 30 秒、净得分决定成色 | 让说明跟随数值配置，避免文案与规则脱节 | `modeInstructions` 提供当前时长及锤数；菜单、首次准备页共用，新增配置变更测试 |
| 节奏、火候一接单就计时，新手没机会看操作 | 第一次开始前允许静止阅读，不消耗耐心，不接受操作，确认后再开始 | 两个场景共用准备页，沿用已有 `seenHint` 存档字段；后续订单自动跳过 |
| 首页帮助写的是时机玩法；关闭提示写空格，但底层开炉按钮也绑定空格 | 帮助覆盖三种玩法，弹层期间屏蔽底层快捷键，点击四角也能关闭 | 首页统一处理快捷键；全屏遮罩捕获点击；空格/Esc/H 只关闭帮助，C 被屏蔽 |
| 结算后 `newGame(config)` 默认变回时机玩法 | 重玩保留当前打法，并给玩家直接换打法入口 | 显式传入当前 mode，新增 M 换打法按钮 |
| 提前结束仍显示“三天到头”；结束存档继续时直接回铺子 | 正确呈现结束状态，防止在已结束存档中继续接单 | 提前收摊标题；恢复存档时先检查 `isFinished` |

## 画面取舍

初版扩充帮助文字后，原木框素材的厚边占用了文字区域。实机查看后改用项目已有的奶油底圆角面板，让正文和底部关闭提示都在可读区域。没有新生成图片。

## 验证

- `npm run check`：类型检查和 39 项测试通过；新增测试验证改变时长/锤数后说明同步更新，且不会改写模式元数据。
- `npm run shot`：封面、菜单、接单与时机场景截图正常，无控制台错误。标准脚本在同一场景重复数次后停止，不视为整局通关。
- `npm run pack`：生成约 14.7 MB 的单文件离线版。
- `node verify/flow.mjs`：开发版和断网 `file://` 离线版均通过。验证帮助框的 Space/Esc/H/C、四角和底层按钮位置点击；等待准备期间时间及耐心不变、方向键不生效；确认后计时恢复；后续订单不重复提示；三种模式重玩保留原模式、M 可换模式、结束存档进入结算。
- 流程回归中的结算用测试状态构造，用于验证导航，不宣称自动完成了一局。游戏规则仍由既有单元测试覆盖。
- 测试最初对弹层生成后立即点击，在 Phaser 注册交互区域前读结果，导致断言失败；改为等待两次动画帧后再点击并等待关闭状态，开发/离线回归通过。
- `node verify/art.mjs`：开发与离线版本的三张新增素材、透明通道和精灵换道仍通过。该脚本以及 `verify/tour.mjs` 已适配新准备页。

本轮未改 `src/engine/`、`src/main.ts`、包依赖和存档格式。离线包按仓库原有规则留在本地，可通过原打包命令重建。
